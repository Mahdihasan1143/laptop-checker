===================================================
   💻 LAPTOP CHECKER – কীভাবে ব্যবহার করবেন
              Made by Mahdi
===================================================

▶ ZIP হিসেবে পেলে: আগে ZIP-এ right-click → Properties → নিচে "Unblock"
  টিক দিন → OK। তারপর right-click → "Extract All" করে খুলুন।
  ZIP-এর ভেতর থেকে সরাসরি চালাবেন না।

▶ শুরুর আগে: charger লাগান, WiFi কানেক্ট করুন, Bluetooth চালু করুন।

★ চালানো: শুধু "START-LAPTOP-CHECK.bat"-এ ডাবল-ক্লিক করুন।
   Admin permission চাইলে "Yes" দিন।

   যা যা হবে (window-এর title-এ সবসময় কত % হলো দেখাবে):
   1) নিজে নিজে চেক – ~৩ মিনিট, শুধু অপেক্ষা করুন।
   2) হাতের চেক – ~৫ মিনিট। স্ক্রিন প্রতিটা ধাপে বলে দেবে কী করতে হবে:
        • স্ক্রিনের রঙ টেস্ট (dead pixel / দাগ / লাইন খুঁজুন)
        • Touchscreen (থাকলে – আঙুল দিয়ে পুরো স্ক্রিনে দাগ কাটুন)
        • Keyboard – key চাপলে ছবিতে সবুজ হবে; ধূসর থাকলে নষ্ট
        • USB পোর্ট – মাউস/পেনড্রাইভ একে একে প্রতিটা পোর্টে লাগান,
          কাজ করলে "USB OK" দেখাবে। HDMI থাকলে টিভি/মনিটরে লাগান।
        • Webcam – Camera app খুলবে, ছবি পরিষ্কার কিনা দেখুন
      প্রতিটা ধাপে ENTER = শুরু, S + ENTER = বাদ।
   3) Heat test – ~১ মিনিট, শুধু অপেক্ষা করুন।
   4) Battery টেস্ট – ১০–৪০ মিনিট। Beep দিলে charger খুলে দিন, আবার
      beep দিলে লাগিয়ে দিন। Q চাপলে আগেই থামানো যায়।
      টেস্টের মাঝে ল্যাপটপ বন্ধ হয়ে গেলে → চার্জ দিয়ে আবার চালান,
      রিপোর্টে লেখা আসবে (battery নষ্ট)।
   5) Speaker+mic আর brightness নিজে নিজে টেস্ট হবে, তারপর রিপোর্ট
      খুলবে (ইংরেজি + বাংলা; চীনা Windows-এ ইংরেজি + চীনা)।
      রিপোর্ট "Reports" ফোল্ডারে সেভ থাকবে।

   রিপোর্টের শেষে "হাতে চেক করুন" তালিকা থাকবে: স্টিকারের Serial,
   BIOS password, বডি, fan-এর শব্দ।

   ⚠ Battery টেস্ট থামাতে Q চাপুন – window X দিয়ে বন্ধ করবেন না
     (তাহলে স্ক্রিনের brightness 100%-এ থেকে যাবে)।
   ⚠ কোনো সমস্যা বা অদ্ভুত ফল হলে "Reports" ফোল্ডারের .log ফাইলটা
     পাঠান (রিপোর্টের নামেই থাকে) – ওটা দেখে সমস্যা ধরা যাবে।

---------------------------------------------------
 রেজাল্ট বোঝার নিয়ম
---------------------------------------------------
 🔴 FAIL  = বড় সমস্যা → এই ল্যাপটপ নেবেন না
 🟡 WARN  = ছোট সমস্যা → দাম কমাতে বলুন
 🟢 PASS  = ঠিক আছে
 ⚪ INFO  = শুধু জানার জন্য

 ⛔ এগুলো FAIL হলে কোনোভাবেই কিনবেন না:
    Computrace / Autopilot (চোরাই বা কোম্পানির লক করা ল্যাপটপ),
    Serial blank, Crash Cause (RAM/SSD/CPU), Disk Scan / SMART
 ⚠ "C: is encrypted (BitLocker)" দেখালে → বিক্রেতাকে তার Microsoft
    account সরাতে বলুন বা recovery key নিন, নইলে পরে লক হয়ে যেতে পারে।

---------------------------------------------------
 বাড়তি টুল (দরকার হলে) – Tools ফোল্ডারে
---------------------------------------------------
 Tools\CrystalDiskInfo\DiskInfo64.exe  → SSD/HDD-এর health (Good = ঠিক)
 Tools\FurMark\FurMark_GUI.exe         → GPU গরমের টেস্ট (৫–১০ মিনিট;
                                         ৯০°C-এর বেশি বা ঝিলমিল = সমস্যা)

 সাথে দেওয়া নেই (দরকার হলে অফিসিয়াল সাইট থেকে নামান):
   CPU-Z (CPU, RAM, Motherboard-এর বিস্তারিত)
         https://www.cpuid.com/softwares/cpu-z.html
   HWMonitor (CPU-এর তাপমাত্রা)
         https://www.cpuid.com/softwares/hwmonitor.html

⚠ দোকানদার চেক করতে দিতে না চাইলে → সেখান থেকে কিনবেন না।
